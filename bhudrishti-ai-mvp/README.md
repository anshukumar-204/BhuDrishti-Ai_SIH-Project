# 🏆 BhuDrishti AI — Land Intelligence Platform

> **Smart India Hackathon 2026 Project**  
> A centralized AI-enabled platform integrating GIS, research, and analytics for land governance in India.

## ✨ Features

- 🗺️ **Interactive GIS Map** — Explore land parcels with 5 toggleable layers
- 📊 **Analytics Dashboard** — Visualize land use trends & risk distribution
- 📚 **Research Hub** — 200+ curated research papers & policy documents
- 🎯 **Parcel Details** — Comprehensive land information & risk assessment
- 🎨 **Modern UI** — Beautiful, responsive design with animations

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn

### Frontend

```bash
cd client
npm install
npm run dev
# Open http://localhost:5173
```
